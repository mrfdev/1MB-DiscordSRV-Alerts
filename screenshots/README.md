# Screenshot Examples

Store only authentic Discord output captured while testing an Alert Recipe. Use:

```text
screenshots/<plugin>/<recipe-slug>/<descriptive-name>.png
```

Reference each image with a repeated `# Screenshot:` field in the matching Recipe header. Before committing, crop the image deliberately and check that it contains no non-localhost player IP address, token, webhook, unrelated private channel, or other unintended data.

Screenshots are optional. A Recipe can be verified without one when its trigger and output were observed but no useful example has been captured yet.
