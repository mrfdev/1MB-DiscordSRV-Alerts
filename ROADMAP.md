# Roadmap

Detailed work is tracked in GitHub Issues. This file records only the project phases so the actionable backlog has one source of truth.

## 1. Repository foundation

- Establish the public/private boundary and publication guards.
- Define the Alert Recipe metadata and versioning contract.
- Add validation, generation, testing, release, and website tooling.

## 2. Live and legacy migration

- Preserve the exact 1MoreBlock Live Profile.
- Review the 35 legacy YAML files and 121 discovered Alert blocks.
- Reconcile exact duplicates and stylistic variants into Canonical Recipes.
- Restore lost credit and origin details from legacy history.

## 3. Runtime verification

- Validate core Paper/Bukkit and DiscordSRV triggers.
- Validate CMI/CMILib, mcMMO, and Jobs Recipes on the private test server.
- Expand plugin coverage only when required dependencies are available.
- Capture authentic Discord Screenshot Examples.

## 4. Public catalog and first release

- Publish the searchable GitHub Pages catalog.
- Generate the verified Recipe ZIP and complete reusable `alerts.yml`.
- Publish collection release `v3.0.0-b001`.

## 5. Broader discovery

- Compare narrowly matched Alert files found on other Macs.
- Review free-to-redistribute web sources.
- Later, inspect the DiscordSRV Discord Alerts forum through the signed-in browser.
