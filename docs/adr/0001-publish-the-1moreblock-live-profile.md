# Publish the 1MoreBlock Live Profile

The exact `alerts.yml` used by 1MoreBlock.com is intentionally versioned in this public repository, including its server-specific channel IDs and behavior, so it can be reviewed, repaired, and restored without reconstructing local values. It is clearly identified as server-specific, excluded from the Release Archive and Complete Alerts File, and never accompanied by DiscordSRV configuration, credentials, account links, logs, worlds, or other Test Server data.
